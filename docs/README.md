# Documentation Index

This directory contains the architecture and development documentation for the Personal Financial Intelligence application.

Follow the pattern: INDEX → SMALL DOCUMENT → TASK.

## Directories
- `architecture/` - Architectural rules and designs
- `decisions/` - Architecture Decision Records (ADRs)
- `domain/` - Domain models and core financial rules
- `contracts/` - Cross-module and API contracts
- `development/` - Setup, workflows, and guides
- `tasks/` - Task-specific tracking and design docs
